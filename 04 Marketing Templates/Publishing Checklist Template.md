# {{title}} — Publishing Checklist

A light authorial checklist spanning pre-writing through post-launch. Use what fits; ignore the rest.

## Pre-writing

- [ ] Define project goals and objectives
- [ ] Preliminary genre / market research
- [ ] Clarify target audience
- [ ] Brainstorm plot, characters, themes
- [ ] Create a timeline with milestones
- [ ] Expected word count set

## Writing

- [ ] Outline / story map complete
- [ ] Character profiles for main cast
- [ ] Setting / world notes established
- [ ] Compelling opening drafted
- [ ] Full draft complete
- [ ] Consistency pass (tone, voice, continuity)

## Editing

- [ ] Developmental revision
- [ ] Beta reader feedback implemented
- [ ] Line / copy edit
- [ ] Proofread

## Publishing prep

- [ ] Path chosen (traditional / self / hybrid)
- [ ] Query letter / synopsis / proposal (if querying)
- [ ] Author platform basics (site, newsletter, social)
- [ ] Cover art / layout plan
- [ ] Permissions secured for any copyrighted material
- [ ] Manuscript formatted to guidelines

## Launch & after

- [ ] ARC / early reader plan
- [ ] Launch marketing outline
- [ ] Events / outreach ideas
- [ ] Sales + reader-feedback monitoring plan
- [ ] Next-project notes
