# Manuscript Guide

This folder is for **actual draft prose** — not planning cards.

## Suggested setup per book

1. Duplicate [[Projects/Project Dashboard Template|Project Dashboard Template]] into `Projects/` and rename it for your book.
2. Inside `02 Manuscript/`, create a folder for that book, for example:
   ```text
   02 Manuscript/
     My Novel Title/
       00 Manuscript Home.md
       Chapters/
         Chapter 01 - Title.md
         Chapter 02 - Title.md
   ```
3. Duplicate [[02 Manuscript/Chapter Template|Chapter Template]] into that book's `Chapters/` folder for each chapter.
4. Keep beat sheets, character profiles, and scene cards in `01 Writing Templates` / linked from the project dashboard — link out to chapters from there.

## What belongs where

| Folder | Put this here |
|---|---|
| `01 Writing Templates` | Premise, beats, characters, scene cards, goals |
| `02 Manuscript` | Full chapter drafts and manuscript home notes |
| `03 Editing Templates` | Beta notes, feedback, revision passes |
| `04 Marketing Templates` | Reviews, interviews, launch content |

## Naming tips

- `Chapter 01 - The Letter.md` sorts cleanly
- Keep chapter numbers zero-padded (`01`, `02`…) so the file list stays in order
- Optional: a `00 Manuscript Home.md` note that lists every chapter with status and word counts
